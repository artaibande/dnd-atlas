# D&D Atlas — prototipo inicial

Este repositorio contiene una primera interfaz jugable local:
- mapa de cuadrícula ilustrativo;
- cuatro personajes de ejemplo;
- movimiento con flechas;
- selección y paso de turno;
- modo mando dentro de la misma página.

## Importante
Esta versión **todavía no sincroniza** ordenadores y móviles distintos. No genera QR definitivos. La sincronización requiere configurar un servicio en tiempo real y añadir una URL pública por personaje. No imprimir QR todavía.

## Publicación
Sube `index.html` y `README.md` a la raíz del repositorio de GitHub. Después podemos activar GitHub Pages para publicar esta interfaz inicial y continuar con la sincronización.
